# 前端改版：规划与组件契约

日期：2026-09-06。用户确认按已展示的图片实现：发现型首页 + 三栏阅读页。视觉参考为 Lightspark 浅色页面，使用独立生成的纸张/玻璃素材，不复用其品牌。

## 从任务出发

1. 已知要找什么：首页搜索和阅读页搜索共用入口与服务端搜索逻辑。
2. 尚不知道文档名称：首页按真实分类展示链接，阅读页提供可折叠目录。
3. 已进入文章：正文优先，标题、面包屑、目录、前后篇全部从同一份文档树和文章响应推导。
4. 小屏幕：保留内容宽度，把侧栏折入模态抽屉，关闭后恢复焦点；文章目录用可展开区域呈现。

## 组件协调

| 组件 | 输入 / 状态来源 | 输出 / 联动 |
|---|---|---|
| 站点顶栏 | 站点名称、当前路径 | 返回首页、搜索对话框、管理入口 |
| 首页分类 | 公共文档树 | 跳转真实文章 URL，不放虚构演示文档 |
| 搜索对话框 | 一个查询、服务端搜索结果 | 选中文章后清理搜索、关闭对话框、同步阅读状态 |
| 文档树 | 公共树、当前路径、折叠集合 | 选中当前文章，自动展开其祖先 |
| 文章 | 当前 URL 对应的响应 | 安全 HTML、标题目录、前后篇、代码复制 |
| 文章目录 | 后端 headings + 当前滚动位置 | 更新活动标题、URL hash，支持刷新深链接 |
| 管理端 | 既有认证和编辑流程 | 沿用新令牌，保留 CRUD 与冲突处理 |

## 执行顺序

先拆分阅读/管理界面职责，再建立统一令牌与共享图标，接入首页和阅读布局，最后验证搜索、历史导航、锚点、抽屉、长标题、空数据和错误状态。

视觉规格：暖白底、近黑文字、低饱和青绿选中态；顶部 72px；主页最大宽度 1280px；文章正文约 720px；细线分隔优先于卡片阴影；中文系统字体，避免外部字体请求。

范围：重做真实前端，不新增后台权限或内容功能，不改变部署方式。首页不再自动跳至第一篇文章；这是发现型首页所需的明确行为调整。图中“墨页”是概念名称，实际站点名称仍取后端配置。

验收：桌面与移动浏览器视觉核对、真实 API 阅读与搜索、前进后退、键盘开关搜索和抽屉、复制反馈、管理员登录布局、生产构建、Go 嵌入兼容性。示例内容只放本次验证的独立数据目录，不写入用户文档库。
